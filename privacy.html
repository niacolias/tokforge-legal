Privacy policy

Last updated: October 1, 2026

tokForge is a personal, self-hosted application used only by its owner to publish videos to the owner's own YouTube channels. It has no other users.

Data accessed through Google

  • YouTube upload access — to publish videos the owner has approved.
  • Channel identity (channel id, name, avatar) — to show which channel is connected.
  • Statistics of videos published by tokForge — so the owner can see how they perform.

How it is stored

OAuth access and refresh tokens are stored encrypted on the owner's own machine. Channel identity and video statistics are stored locally in the same place. Nothing is sent to any server operated by tokForge — there is none.

Sharing

tokForge does not sell, share, or transfer any Google user data to third parties, and does not use it for advertising. Data is only sent to YouTube's own API to perform the actions above.

tokForge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept until the owner disconnects the channel in tokForge, which deletes the stored tokens. Access can also be revoked at any time at myaccount.google.com/permissions.
